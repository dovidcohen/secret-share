Share a password as a one-time link

A link that works exactly once, for exactly one person, then ceases to exist.

The everyday cases: onboarding someone onto a shared account, handing the Wi-Fi or router admin password to a guest, giving a family member access to something, or passing credentials during a handover. The wrong ways are familiar — texting it, emailing it, or the classic "I'll send half by email and half by WhatsApp," which mostly doubles the number of places it's stored forever.

If both of you already use a password manager with shared vaults (1Password, Bitwarden, etc.), use that — organized, permanent, revocable sharing is exactly what vaults are for. One-time links are for everyone else, and for the cases where the recipient is outside your vault: contractors, family, one-off handovers.

Why "one-time" is the property that matters

A password sent over chat can be read by anyone who ever gets into that conversation — next month or in five years. A one-time link inverts the odds: after the intended person opens it, there is nothing left to steal. And if someone else opens it first, the intended recipient finds out immediately (their link is dead), which turns a silent breach into a loud one. Add an expiry and even an unopened link stops being a liability.

Step by step

  1. Open shareasecret.io and paste the password. It's encrypted in your browser before anything is sent anywhere.
  2. Pick an expiry — 1 hour if they're waiting, 24 hours by default, up to 7 days.
  3. Send the link over any channel, or read the short code aloud on a call. The unlocking words never touch a server, so the channel you use only ever sees a pointer, not the password.
  4. The recipient opens it once; the copy is destroyed on read. Five wrong code attempts also destroy it. You can hit Destroy secret now at any time before pickup.

What to tell the recipient

  • "This link works once — open it when you're ready to save the password properly."
  • "If it says already retrieved and you didn't open it, tell me right away." (That's the tamper alarm working.)
  • "Change the password after first login if the account supports it."
